# Rubix-Cube-3js

This project is an experiment with the Three.js library to create a 3D representation of a Rubik's Cube. It serves as a learning exercise to explore the capabilities of Three.js for rendering and manipulating 3D objects in a browser.

## Features

- Interactive 3D Rubik's Cube
- Experimentation with Three.js rendering and animations

## Setup Instructions

1. Clone this repository:
   ```
   git clone https://github.com/PragalvhaSharma/Rubix-Cube-3js.git
   ```
2. Navigate to the project directory:
   ```
   cd Rubix-Cube-3js
   ```
3. Install the dependencies:
   ```
   npm install
   ```
4. Start the development server:
   ```
   npm start
   ```
5. Open your browser and navigate to `http://localhost:3000`.

## Technologies Used

- [Three.js](https://threejs.org/) for 3D rendering
- [React](https://reactjs.org/) (if applicable, depending on your setup)
- Basic JavaScript, HTML, and CSS
